Техническое задание

Эталонные расчёты

Автономная проверка формул. Это технический пример, не готовый дизайн сайта. Модели сторонних инструментов; соответствие игровому серверу не доказано.

1. Базовые статы

Базовые значения без бонусов и реликвий. Порядок: HP / SPD / EA / PA / ED / PD.

2. Прямой урон Hub

Условие: все удары попали, без критов/щитов/ядов. Для физического навыка вводить PA/PD, для стихийного EA/ED. Число применений до KO — границы по суммарному урону навыка, без ответных действий и лечения.

3. Ребонус по модели Nekkoyato

Начальные бонусы — демонстрационный профиль. 136 очков; минимум 1 на стат. Выберите до 5 пониженных приоритетов. Seed задаёт воспроизводимую последовательность этого примера, не Godot/игры.

Монте-Карло оценивает выбранную модель и событие PA ≥ порог. 95% интервал Уилсона отражает выборочную погрешность, а не достоверность игровой формулы. Этот небольшой пример считает синхронно; production обязан использовать Worker.
