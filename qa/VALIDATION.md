# Выполненные проверки
- Python-валидатор: схемы нормализованных сущностей, уникальные ID, внешние ключи, принадлежность зоны локации, соответствие маркеров семейству и карте, диапазоны координат, наличие включённых изображений, локальные HTML-ссылки, совпадение чисел покрытия. Детальный результат data-validation.json.
- Node: 20 контрольных тестов математического ядра; в том числе10 000 выборок с проверкой инвариантов и отдельный проход всех d=0…5. Лог core-test-results.txt.
- Синтаксис встроенного JS автономных страниц проверен Node; javascript-syntax.json.
- 12 карт просмотрены в контактном листе maps-contact-sheet.jpg: изображения содержат соответствующие игровые карты без браузерных полей и наложенных маркеров. Метаданные реального разрешения в maps.json.
- Проверен cmap Miscria: русских букв нет; системный fallback указан.
- Полный browser smoke-test автономных HTML не выполнен: среда проверки запрещает file://. Поэтому здесь не заявляются выполненные браузерные UX-тесты, мобильные замеры или performance-аудит будущего сайта. Приёмочные сценарии для исполнителя описаны в docs/11_ACCEPTANCE_PLAN.md.
- Финальный manifest содержит SHA-256 каждого включённого файла. manifest не включает сам себя. Проверка архива ZIP выполняется перед передачей.

Это проверки комплекта данных и reference code. Они не подтверждают соответствие всех механик живому игровому серверу и не заменяют тестирование будущей реализации.
