# Miscrits Encyclopedia

Автономный React/Vite интерфейс поверх данных из `data/`.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки: `npm run build`, затем `npm run preview`.

В приложении доступны каталог с общими фильтрами и URL-состоянием, карточка семейства, карта с нормализованными координатами, локальная коллекция на IndexedDB с экспортом/импортом, калькулятор прямого урона и симулятор ребонуса. Изображения мискритов в исходном комплекте отсутствуют, поэтому карточки используют подписанный нейтральный силуэт; карты и реликвии подключены из включённых ассетов.

Эталонные математические проверки исходного комплекта запускаются отдельно: `node qa/core.test.cjs`. Полная production-сборка содержит крупные статические справочники abilities и требует дальнейшего code splitting при росте набора данных.
